# marketOS-digital-marketing

> **"Give us the business. We'll build the marketing."**

MarketOS is a focused, powerful **AI Digital Marketing Department** built for local businesses and digital marketing operators. 

Enter basic information about any local business, and MarketOS autonomously crafts a complete digital marketing solution with targeted strategy, 5–10 campaign ideas, multi-channel copy, and production-ready visual creatives.

---

## ✨ Features

- **Minimalist Business Intake**: Single-screen form capturing business name, category, location, products/services, USP, offers, and optional logo/product assets.
- **Autonomous AI Strategy**: Instantly formulates market positioning, target audience demographics, cultural & localized angles, and tone of voice.
- **High-Impact Campaigns**: Generates 5–10 distinct campaign concepts with clear hooks, objectives, and CTAs.
- **Multi-Channel Copy Generation**:
  - **Instagram**: Ready-to-post captions with curated hashtags
  - **WhatsApp**: Direct-response promotional broadcasts
  - **Reels**: 30-second scripts (Hook, visual scene breakdown, voiceover, audio cues, CTA)
  - **Stories**: 3-frame sequential narrative copy
  - **Facebook**: Conversational social copy
- **Production-Ready Visual Creatives**:
  - High-resolution HTML5 canvas rendering across standard formats:
    - Instagram Portrait (`1080 × 1350`)
    - Instagram Square (`1080 × 1080`)
    - Instagram Story / Reel Cover (`1080 × 1920`)
    - Facebook Banner (`1200 × 628`)
  - Seamlessly integrates uploaded product photos and brand logos
  - 3 distinct creative concepts per campaign (Product-focused, Offer-focused, Urgency/Lifestyle)
  - 1-click style & language modifiers (*Make More Premium*, *Make More Local*, *Make More Sales-Focused*, *Make More Minimal*, *Make it Hindi*, *Make it Hinglish*)
- **1-Click Campaign Pack Export**: Bundles the executive strategy markdown, multi-channel copy files, rendered PNG creatives, and JSON data into a single downloadable ZIP.
- **Plan History**: Local persistence allowing one-click retrieval of previously generated marketing plans.

---

## 🚀 Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Creative Engine**: HTML5 Canvas, `html2canvas`
- **Packaging**: `jszip`

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Mayurkothari2827/marketOS-digital-marketing.git
cd marketOS-digital-marketing

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build for Production

```bash
npm run build
```
